# Description
This repository contains code supporting the analysis of single-cell RNA-sequencing data to detect circulating tumour cells (CTC) from cerebrospinal fluid (CSF) in paediatric brain tumour patients enrolled on the ZERO childhood cancer program. This data is being described in a manuscript Mayoh, Li et al which is currently under review. The preprint is available here https://doi.org/10.64898/2025.12.18.694991.

# How-to
This repository contains scripts used to minimally process and prepare data associated with the ZERO Childhood Cancer Liquid Biopsy circulating tumour cell analyses described in Mayoh, Li et al.
Typical usage:

- Place input data files in the appropriate input directory as structured for this specific analysis.
- Run the scripts in the script/ directory in the order indicated by their filenames.
- Scripts perform data cleaning, formatting, and identifier handling to generate submission‑ready outputs.

These scripts are intended to support reproducibility and data standardisation, and may require adaptation for use with external datasets.
Disclaimer: These scripts were developed for internal research workflows and reflect the data structures and conventions of the Liquid Biopsy ZERO Childhood Cancer Program. External users may need to modify paths, inputs, or metadata handling.
